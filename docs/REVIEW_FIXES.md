## Quality gates

- Backend coverage includes all application modules, including seed/setup modules, with branch tracking and a combined minimum of 80%.
- Frontend V8 coverage includes application TypeScript/TSX (excluding test fixtures, pure type declarations and the boot entry): at least 80% lines, 75% statements, 70% functions and 65% branches.
- mypy checks application bodies and annotated contracts; it is not advertised as Python strict mode. TypeScript remains strict.
- PostgreSQL-specific tests are explicitly marked and skipped only in the fast SQLite run. The CI backend job supplies PostgreSQL, so those tests run there.
- Coverage HTML/LCOV/XML artifacts are retained by CI. Hosted results are linked from the README badges.
